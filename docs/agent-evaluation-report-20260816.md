# 科研助手 Agent 端到端评测报告

- 评测日期：2026-08-16
- 测试集：`agent_resume_cases.json` v1，40 条人工标注用例
- 用例构成：20 条知识库问答、10 条计算/代码工具、5 条 arXiv 检索、5 条通用质量问题
- 执行模型：`gpt-5.6-luna`（由于原辅助模型限流，本轮关闭 aux route）
- 会话存储：SQLite（本机 Redis 未启动）
- 并发数：4；单用例超时：90 秒

## 结果

| 指标 | 结果 | 口径 |
|---|---:|---|
| Task Success Rate | 52.50% | 21/40，包含 2 条基础设施超时 |
| 有效样本任务成功率 | 55.26% | 21/38，排除 2 条执行超时 |
| Answer Correctness | 89.47% | 38 条有效回答；Token F1 + 人工标注关键事实覆盖 |
| Groundedness | 79.32% | 22 条含工具证据的回答；`gpt-5.6-luna` Judge |
| Tool Call Success Rate | 87.80% | 36/41 次工具调用执行成功 |
| P50 Latency | 24.32 s | 端到端单任务延迟 |
| P95 Latency | 87.92 s | 包含工具链路与上游网络抖动 |

## 解读

1. 答案关键事实覆盖较好，但任务成功率明显更低；主要差距来自未按预期调用工具、工具结果未完成最终收敛以及关键内容缺失。
2. 工具调用本身成功率为 87.80%，但工具选择准确率仅 68.57%，说明执行器较稳定，路由策略仍需优化。
3. P95 较高，本轮明显受模型代理连接中断、Chroma HTTP 不可用和 arXiv 链路影响。
4. Groundedness 仅在能恢复真实工具证据的 22 条上计算，不应写成全部 40 条的统计。

## 简历建议写法

> 构建 40 条人工标注的 Agent 端到端评测集，覆盖知识库问答、计算/代码工具与论文检索；实测答案正确率 89.47%、事实忠实度 79.32%、工具调用成功率 87.80%，并通过任务成功率与 P95 延迟定位 Agent 路由及上游服务瓶颈。

不建议把 52.50% 任务成功率与 87.92 秒 P95 当作成果数字强调；它们应用于指导下一轮优化，优化后用同一数据集复测。
